# BMX Supercross 3D

Prototype game browser 3D menggunakan Three.js.

## Menjalankan
- Buka folder ini dengan server lokal (misalnya VS Code Live Server), atau upload semua file ke repository GitHub.
- Untuk GitHub Pages: Settings → Pages → Deploy from a branch → pilih `main` dan folder `/ (root)`.
- Buka URL GitHub Pages dari browser.

Catatan: game memakai Three.js dari CDN, jadi perlu koneksi internet saat dimainkan.
Kontrol: GAS, REM, KIRI/KANAN, LOMPAT. Pada desktop tombol yang sama bisa diklik.
