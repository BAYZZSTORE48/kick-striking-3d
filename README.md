# Kick Striking 3D

Game pertarungan 3D sederhana berbasis Three.js. Kontrol mobile:
- Joystick kiri: bergerak
- PUNCH: serangan pukulan
- KICK: serangan tendangan

## Menjalankan melalui GitHub Pages
1. Buat repository baru di GitHub, misalnya `kick-striking-3d`.
2. Pilih **Public** (atau pastikan Pages tersedia untuk repository Anda).
3. Upload `index.html` ke bagian paling atas/root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
7. Tunggu proses selesai. Buka alamat `https://USERNAME.github.io/kick-striking-3d/`.

Game memerlukan internet karena Three.js dimuat dari CDN.
