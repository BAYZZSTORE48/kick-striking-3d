# Kick Striking 3D V2
Mobile Three.js stickman fighting prototype. Includes profile creation, selectable skin/hair/hair style, Fighter/Influencer identity, fighting discipline, local profile persistence, joystick, Jab, Elbow, Kick, Block and CPU opponent.

Update existing GitHub Pages:
1. Open repository `kick-striking-3d`.
2. Open `index.html` and choose Edit (pencil), or Add file > Upload files.
3. Replace the old `index.html` with this new one and commit changes.
4. Wait for Pages deployment, then reload the website. If cached, open in an incognito tab.

Profiles use browser localStorage and stay on that browser/device. Cross-device accounts require a backend and authentication; GitHub Pages alone is static hosting.
