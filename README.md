# BMX Supercross 3D V2
Upgrade prototype: BMX dengan detail rangka, ban, velg, jari-jari, pembalap, trek dan pepohonan yang lebih detail.

## Update GitHub
1. Ekstrak ZIP.
2. Buka repository `kick-striking-3d`.
3. Upload dan replace `index.html`, `style.css`, dan `game.js` dari folder ini.
4. Commit changes.
5. Tunggu GitHub Pages selesai deploy lalu refresh website (bila perlu hard refresh).

Game memakai Three.js dari CDN, jadi perlu koneksi internet.
